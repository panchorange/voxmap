# design-lookup

voxmap の設計に関する質問に答えるとき、Obsidian で書かれた設計書を最優先で参照する。

## いつ起動するか

- ユーザーが「〜の設計どうなってる?」「Pipelineのインタフェースは?」など、コードよりドキュメントに書かれていそうな話題を出したとき
- 新しいコンポーネントを追加する前、設計の前提を確認したいとき
- アーキテクチャ判断 (どこに何を置くか) で迷ったとき

## 手順

1. `docs/` (Obsidian保管庫) を `ls -R` で構造把握する
2. 関連しそうな `.md` を `grep -ri <keyword> docs/` で探す
3. ヒットしたファイルを Read する。Obsidian の `[[link]]` 記法はリンク先のノートも追跡する
4. 設計書の内容を踏まえて回答する。コードと矛盾している場合は「設計書はXと言っているがコードはYになっている」と明示する

## 注意

- `docs/` 配下にあるのはユーザー自身が書いた設計意図。勝手に書き換えない
- 設計書が無い領域では普通にコードを読んで答える
